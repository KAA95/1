# Библиотека шагов Vanessa Automation

Каталог предназначен для проектирования и хранения материалов библиотеки шагов. В реальном 1С-проекте шаги могут быть реализованы в обработках Vanessa Automation, внешних обработках или подключаемых модулях, принятых в команде.

## Принципы проектирования шагов

1. **Повторное использование.** Один шаг должен применяться в разных сценариях, если действие одинаковое по смыслу.
2. **Бизнес-язык.** Шаг описывает действие пользователя или ожидаемый результат, а не внутренний метод 1С.
3. **Устойчивость.** Шаг не должен зависеть от случайного порядка строк, текущей даты или временных задержек без явного ожидания.
4. **Изоляция данных.** Шаги подготовки создают данные с префиксом `АТ_`.
5. **Диагностика.** При ошибке шаг должен оставлять понятное сообщение, лог и по возможности скриншот.

## Проектируемые группы шагов

| Группа | Примеры |
|---|---|
| Авторизация и запуск | `Дано пользователь "..." авторизован в информационной базе` |
| Навигация | `Когда пользователь открывает список документов "..."` |
| Работа со справочниками | `И в базе существует контрагент "..."` |
| Работа с документами | `И пользователь проводит документ` |
| Проверки результата | `Тогда документ должен быть проведен без ошибок` |
| Работа с отчетами | `И пользователь формирует отчет` |
| Права доступа | `Тогда система должна запретить выполнение операции` |
| Интеграции | `Когда пользователь запускает обработку обмена "..."` |

## Пример соответствия сценария и реализации

```gherkin
Когда пользователь проводит документ
Тогда документ должен быть проведен без ошибок
```

Реализация этих шагов должна:

- найти текущую форму документа;
- выполнить команду проведения;
- дождаться завершения операции;
- проверить отсутствие критических сообщений;
- проверить признак проведенности;
- записать диагностическую информацию при ошибке.
