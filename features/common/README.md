# Общие соглашения для BDD-сценариев

В этом каталоге фиксируются общие подготовительные действия и соглашения, которые используются во всех наборах тестов.

## Правила оформления

- Сценарий должен описывать бизнес-поведение, а не внутреннюю реализацию.
- Названия шагов пишутся на языке пользователя.
- Тестовые объекты создаются с префиксом `АТ_`.
- Сценарий не должен зависеть от результата другого сценария.
- Текущая дата должна задаваться явно, если от нее зависит результат.
- Нестабильные проверки временно помечаются `@unstable`, но для них обязательно создается задача на исправление.

## Базовые теги

- `@smoke` — минимальные проверки.
- `@critical` — критичные бизнес-цепочки.
- `@regression` — расширенная регрессия.
- `@document` — документы 1С.
- `@report` — отчеты.
- `@rights` — права доступа.
- `@integration` — обмены и интеграции.
