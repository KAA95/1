# Тестовые данные

Тестовые данные являются критичным элементом воспроизводимости сценарного тестирования 1С.

## Принятый подход

В пилотном репозитории применяется комбинированная модель:

1. **Эталонная база** содержит базовые справочники, пользователей, роли, настройки учета и минимальные остатки.
2. **Сценарии создают временные данные** для конкретной проверки.
3. **Все тестовые объекты имеют префикс `АТ_`**, чтобы их можно было отличить от прочих данных.
4. **CI-контур восстанавливается перед прогоном** из эталонной копии или очищается подготовительной обработкой.

## Что хранить в этом каталоге

- описания тестовых наборов данных;
- обработки подготовки данных;
- JSON/CSV-файлы для загрузки справочников;
- инструкции по восстановлению эталонной базы;
- правила очистки данных после локального запуска.

## Что не хранить

- продуктивные выгрузки баз;
- реальные персональные данные;
- пароли и строки подключения;
- большие бинарные файлы без необходимости.
