# Seed-данные и обработки подготовки

Поместите сюда файлы, которые используются для подготовки тестовой базы:

- внешние обработки 1С для создания справочников и документов;
- шаблоны CSV/JSON для загрузки тестовых данных;
- инструкции по обновлению эталонной базы.

В демонстрационном шаблоне реальные обработки не включены, так как они зависят от конкретной конфигурации 1С.
