# Definition of Done для задачи в 1С-проекте

Задача считается готовой к приемке или включению в релиз, если выполнены следующие условия.

| Критерий | Описание | Ответственный |
|---|---|---|
| Требования уточнены | Ожидаемое поведение описано через критерии приемки | Аналитик |
| Сценарии определены | Для критичных проверок подготовлены или обновлены BDD-сценарии | Аналитик, тестировщик |
| Код реализован | Изменения внесены в конфигурацию, расширение или модуль 1С | Разработчик 1С |
| Локальная проверка выполнена | Разработчик или тестировщик выполнил минимальный набор проверок | Разработчик, тестировщик |
| Smoke/critical пройдены | Обязательные сценарии завершились успешно | CI/CD, тестировщик |
| Артефакты сохранены | Логи, отчеты и скриншоты доступны в workflow | DevOps, CI/CD |
| Замечания обработаны | Дефекты исправлены или оформлены как отдельные задачи | Команда |
| Изменение принято | Функциональность соответствует критериям приемки | Руководитель проекта, аналитик |

## Правило качества

Если падает `@smoke` или `@critical` сценарий, изменение не должно попадать в основную ветку без анализа причины падения.
