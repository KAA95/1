# Метрики оценки эффективности пилота

Для 3 главы ВКР можно использовать сравнение состояния до и после внедрения пилота.

| Метрика | До внедрения | После внедрения | Ожидаемый эффект |
|---|---:|---:|---|
| Время smoke-проверки | Заполняется по факту | Заполняется по факту | Сокращение времени первичной проверки |
| Количество ручных повторных проверок | Заполняется по факту | Заполняется по факту | Снижение трудоемкости регрессии |
| Доля сценариев с автозапуском | 0% | Заполняется по факту | Рост воспроизводимости |
| Количество дефектов после релиза | Заполняется по факту | Заполняется по факту | Снижение регрессионных дефектов |
| Количество ложных падений | Не применимо | Заполняется по факту | Контроль стабильности автотестов |
| Время анализа падения | Заполняется по факту | Заполняется по факту | Ускорение диагностики за счет артефактов |

## Формула снижения трудоемкости

```text
Экономия времени = Время ручной проверки до внедрения - Время анализа автоматизированного прогона после внедрения
```

## Пример описания результата

После внедрения smoke-набора ключевые проверки стали выполняться автоматически при pull request. Это позволило раньше выявлять дефекты в создании и проведении документов, а также фиксировать результаты проверки в виде отчетов и логов CI/CD.
