# CI/CD-пайплайн сценарного тестирования

Основной workflow находится в `.github/workflows/1c-scenario-tests.yml`.

## Этапы пайплайна

| Этап | Содержание | Результат |
|---|---|---|
| Checkout | Получение файлов репозитория | Код и сценарии доступны runner |
| Restore test base | Восстановление эталонной базы или подготовка данных | База приведена к контролируемому состоянию |
| Run scenario tests | Запуск Vanessa Runner по выбранным тегам | Выполнены BDD-сценарии |
| Collect artifacts | Сбор логов, отчетов, скриншотов и параметров запуска | Материалы доступны для анализа |
| Upload artifacts | Публикация артефактов в GitHub Actions | Команда видит результат проверки |

## Условия запуска

| Набор | Условие | Решение по результату |
|---|---|---|
| `@smoke` | Каждый pull request | Падение блокирует слияние до анализа |
| `@critical` | Перед слиянием в основную ветку или перед релизом | Падение требует исправления или управленческого решения |
| `@regression` | Перед релизом или по расписанию | Падение блокирует релиз до разбора |
| `@rights` | При изменении ролей и профилей | Требуется проверка модели доступа |
| `@report` | При изменении отчетов, регистров, расчетов | Требуется анализ данных и алгоритмов |
| `@integration` | При изменении обменов | Требуется проверка интеграционного контура |

## Артефакты

- лог Vanessa Runner;
- отчет Vanessa Automation;
- скриншоты ошибок;
- параметры запуска;
- версия ветки и коммита;
- список нестабильных тестов, если используется тег `@unstable`.
