# Управление тестовыми данными и восстановление состояния

## Цель

Обеспечить одинаковое начальное состояние тестовой базы перед каждым автоматизированным прогоном.

## Правила

- тестовые объекты имеют префикс `АТ_`;
- данные сценария создаются самим сценарием или подготовительной обработкой;
- CI-контур восстанавливается из эталонной копии перед прогоном;
- сценарии не должны зависеть от результатов предыдущих сценариев;
- продуктивные данные не используются без обезличивания.

## Варианты восстановления

| Вариант | Когда применять |
|---|---|
| Восстановление из `.dt` | Для файловой базы или простого CI-контура |
| Копирование эталонной файловой базы | Для быстрых smoke-прогонов |
| Очистка тестовых объектов по префиксу | Для общего тестового контура |
| Подготовительная обработка 1С | Для сложных конфигураций с зависимыми справочниками |
